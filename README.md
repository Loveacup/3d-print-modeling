# 3d-print-modeling

理解人的诉求并推进完整3D打印项目：研究设计、建模、视觉表达、制造优化、装配验收和问题迭代。**公开版 1.4.0**，从 [SKILL.md](SKILL.md) 开始，按当前问题读取参考；每轮调整先读当前项目自己的核心需求。

- 主模型亲自承担设计和问题解决，连接专业技能，不只是派任务或调整切片参数。
- 建模与视觉表达并列为核心：原创/逆向、接口/装配、草图、爆炸图、分析图、尺寸图与产品图按问题选择。
- 联动摆向、摆盘、分色、Z缝、支撑、层高、速度/流量/温度/冷却及后处理；必要时返回结构设计，不以单项省料或免支撑代替整体取舍。
- 有可用项目管理软件时连接其协作skill（如 `linear-flow`），没有就在项目内管理成果、责任、依赖、阻塞、决定与验收；已有系统断联不静默另立正本。
- 当前环境已有Jev时，主动按需比较技能组合、建模路线、参数及切片候选，不必等卡住；已知规则直接计算。Jev给的是建议，几何、真实刀路和实物仍分别验证，没有净收益数据不宣称加速节费。
- 每次有明确范围的工作完成、暂停或交接，将问题查重归集，有依据的经验合并到知识与读取入口；下次应用、验证并用反例纠错。无新增就简记，不造issue或堆规则。
